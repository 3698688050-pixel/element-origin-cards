# 元素词源卡片

元素周期表前 36 号元素的英文名是从哪来的：拉丁、希腊、神话、地名、矿物。一张卡片一个元素，翻面看词根拆解。

H 是「造水者」（hydro- 水 + -gen 产生），He 来自希腊太阳神 Helios，Li 来自希腊语 lithos（石头），Be 来自绿柱石 beryl —— 元素名大多不是凭空起的，背后总有一个具体的东西。

**在线使用**：https://3698688050-pixel.github.io/element-origin-cards/

## 内容

- 覆盖 1–36 号元素（H 到 Kr）
- 卡片正面：中文名、元素符号、英文名；翻面看词源拆解
- 按词源归为五类，各有配色：性质、神话/天体、地名、矿物、古名
- 卡片下方是 36 格周期表，点格子直接跳到该元素
- 上一张 / 翻面 / 下一张 / 随机，可勾「自动翻面」当屏保循环看

## 本地运行

双击 `index.html`，无外部依赖，断网可用。
